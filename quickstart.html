Two minutes to check every MCP server you have

Scan the servers you already have installed, then set up protection for future installs. Requires Credence installed as an MCP server or CLI.

Step 1

Scan what you already have

Copy this prompt and paste it into Claude Desktop, Claude Code, or any MCP client with Credence installed.

I have Credence installed as an MCP server. Please use the credence_audit_config tool to check all MCP servers in my config. For each server, tell me: - Whether it's attested by Credence - Its trust score and verdict - Any flags or concerns List the unattested servers separately so I can submit them for scanning.

Your agent will call credence_audit_config, which reads your MCP client config and checks each server against the registry. No data leaves your machine except the registry lookup.

Run from your terminal:

credence audit

Auto-detects your Claude Desktop or Claude Code config. Use --config PATH for a custom location.

Step 2

Protect future installs

Set it up once so every new MCP server gets checked automatically.

Wrap any install command with credence guard. If the server isn't attested, the install doesn't run.

# Check trust, then install — only if attested
credence guard owner/mcp-server -- claude mcp add my-server

# Works with any install command
credence guard owner/mcp-server -- npm install @owner/mcp-server

Exit code 0 = attested, install runs. Exit code 1 = not attested, install blocked. Exit code 3 = rejected, install blocked. Full exit code reference.

Add a shell alias so trust checks happen automatically whenever you install an MCP server.

# Add to ~/.bashrc or ~/.zshrc
mcp-install() {
  credence guard "$1" -- "${@:2}"
}

# Usage
mcp-install owner/mcp-server claude mcp add my-server

The first argument is the server identifier for the Credence lookup. Everything after is the install command that runs only if the server is attested.

Run credence watch in the background. It monitors your MCP client config and alerts you when a new unattested server appears.

# Start watching (runs until you stop it)
credence watch

# Watch a specific config file
credence watch --config ~/Library/Application\ Support/Claude/claude_desktop_config.json

Best for Claude Desktop, which doesn't have a hook mechanism for installs. The watcher detects config changes and prints alerts for unattested servers.

Step 3

Submit unattested servers

Unattested doesn't mean unsafe — it means the server hasn't been scanned yet. If your audit found unattested servers, submit them for analysis and they'll go through the full Credence pipeline: identity verification, code scanning, adversarial deliberation, and signed attestation.

01

Submit the server

Use the submission form with the repository URL and server name. It creates a GitHub Issue to track the scan.

02

Pipeline runs

Credence clones the repo, runs the scanner suite, and five AI agents debate the findings. Results are posted to the GitHub issue.

03

Re-run your audit

Once the attestation is published, re-run credence audit and the server will show up with a trust score.
